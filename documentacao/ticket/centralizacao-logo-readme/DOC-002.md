# Centralizar o logo e remover o título redundante do README

## Objetivo

Exibir o logo oficial centralizado na renderização do GitHub e remover o título `# Squad System`, redundante com a identidade visual.

## Contexto

O README usava CSS inline para centralizar a imagem, mas essa apresentação não estava centralizada no GitHub. O título repetia o nome já presente no logo.

## Escopo

- Remover o heading `# Squad System` do início do README.
- Envolver o logo oficial em `<p align="center">`, preservando `src`, texto alternativo e largura.
- Proteger o novo contrato visual no teste documental.

## Definition of Done

- [x] O título redundante foi removido.
- [x] O logo usa centralização compatível com GitHub.
- [x] O teste rejeita logo fora do contêiner centralizado.
- [x] O teste relevante e a suíte completa passam.

## Critérios de Aceite

- O início do README não contém o heading `# Squad System`.
- O logo oficial, com alternativa acessível e largura válida, está dentro de `<p align="center">`.
- A validação falha se o alinhamento central for removido ou se `src`, `alt` ou `width` forem inválidos.
