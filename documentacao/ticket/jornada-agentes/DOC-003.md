# Diagrama da jornada dos agentes da Squad System

## Objetivo

Disponibilizar uma visualização autocontida da jornada de trabalho entre usuário, líder, analista, dev e reviewer.

## Contexto

O README descreve os papéis, gates e retornos do fluxo operacional, mas não oferece uma visão gráfica exportável.

## Escopo

- Fonte editável em JSON no formato `sequence` do Archify.
- HTML autocontido com temas claro/escuro e exportação de imagem e SVG.
- Fluxo principal, gates do usuário, testes, revisão e caminhos de ajuste ou nova demanda.

## Definition of Done

- JSON e HTML gerados e validados pelo Archify.
- Jornada protegida por teste automatizado.
- Suíte completa aprovada.

## Critérios de Aceite

- Exibir as raias Usuário, Líder, Analista, Dev e Reviewer.
- Evidenciar aprovação do plano, testes iniciais, revisão técnica e aceite explícito.
- Explicar reprovação, ajuste pontual no mesmo ticket e novo objetivo como nova demanda.
- Permitir alternância de tema e exportação.

## Lacunas Bloqueantes

Nenhuma.

| 7 | REPROVADO | Link relativo não executa HTML interativo no GitHub; orientação precisava explicitar download local. |
| 8 | APROVADO | Prévia posicionada no README e orientação corrigida para baixar e abrir o HTML localmente. |

| Ciclo | Feedback | Classificação | Resultado |

| 1 | Fluxo confuso e texto quebrado nos nós de Testes/TDD. | Ajuste pontual | Reestruturação como sequência cronológica. |
